# Музыка DavCode

Проверено 17 сентября 2026 года. В комплекте **6 разных инструментальных записей**: 2 рэп-бита, 2 хип-хоп-трека, 2 электронные композиции. Это не полная запрошенная подборка из 8–10 треков: **не хватает двух треков фонк**. Они не заменены другими жанрами и не представлены фиктивными строками плеера.

Кандидаты: [Phonk ish](https://freemusicarchive.org/music/holiznacc0/phonk-aura-farming/phonk-ish/) и [Phonk Remix](https://freemusicarchive.org/music/holiznacc0/phonk-aura-farming/phonk-remix/) — HoliznaCC0, CC0 1.0, инструментальные записи с альбома PHONK - AURA FARMING. Метаданные доступны в поисковом индексе, но прямое обращение к источнику возвращает HTTP 403. Аудио не скачано и в проект не включено. Для завершения подборки нужны эти два разрешённых файла либо две другие явно лицензированные инструментальные фонк-композиции.

## Проверка и ограничения

Все шесть файлов полностью декодированы, имеют ненулевой аудиосигнал, разные контрольные суммы и размеры меньше 25 МБ. OGG перекодированы в MP3 для совместимости. Файлы запускаются только по нажатию, preload="none". Полноценное прослушивание в браузере в этой среде недоступно; перед школьной демонстрацией рекомендуется прослушать подборку целиком.

Оформление обложки создано CSS/SVG средствами сайта и не использует чужие фотографии. Короткие эффекты генерируются Web Audio API и не содержат сторонних записей.
