# DavCode — учись и создавай

Школьный проект Русинова Давида, ученика 11А класса. Учебный сайт на обычных HTML, CSS и JavaScript. Регистрация, сервер и сборка не нужны. Сайт не обращается к внешним сервисам и работает без интернета после скачивания.

## Как открыть локально

1. Распакуй архив `davcode-site.zip` в отдельную папку.
2. Открой `index.html` двойным щелчком в современном браузере.
3. Начни с раздела «Уроки». Правильный ответ в конце урока отмечает его пройденным.

При необходимости можно открыть эту папку через любой локальный статический сервер. Например, если установлен Python: `python -m http.server 8000`, затем открыть `http://localhost:8000`. Это только способ просмотра; серверная часть у сайта отсутствует.

## Как опубликовать на GitHub Pages

1. Создай репозиторий GitHub (для бесплатной публикации — публичный).
2. Выбери **Add file → Upload files** и загрузи **распакованное содержимое архива**, а не сам ZIP и не внешнюю папку. `index.html` должен находиться в корне репозитория рядом с `styles.css`, `data.js`, `app.js`, `certificate.js` и `favicon.svg`.
3. Сохрани файлы кнопкой **Commit changes** в выбранной ветке, например `main`.
4. Открой **Settings → Pages**. В блоке **Build and deployment**, поле **Source**, выбери **Deploy from a branch**.
5. Выбери ветку `main` (или ту, куда загружены файлы), папку **/(root)** и нажми **Save**.
6. Дождись публикации. Ссылка на сайт появится в разделе Pages. Обычно адрес имеет вид `https://username.github.io/repository/`.

Относительные пути и переходы через `#` позволяют сайту работать внутри папки репозитория. Инструкция сверена с [документацией GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Что внутри

- 6 уроков Python и 2 урока HTML/CSS, по 2–3 примера и проверочный вопрос в каждом.
- 12 заданий с фильтром, подсказками, проверкой и повторной попыткой.
- Тест Python из 10 вопросов и HTML/CSS из 5 вопросов. Для сдачи нужно от 70%. Сохраняется лучший результат; ответы показываются только после завершения.
- Прогресс и три достижения. Общий процент: (пройденные уроки + решённые задания + сданные тесты) / 22 × 100%, с округлением.
- Два отдельных сертификата. Для каждого нужны все уроки соответствующего направления и сданный тест. Дополнительные задания необязательны.
- Предпросмотр и скачивание настоящих PNG и PDF формата A4, горизонтально. Сертификат рисуется в разрешении 2400 × 1697 пикселей. Кириллица становится частью изображения, поэтому не зависит от шрифтов на устройстве, открывающем PDF. Текст PDF не выделяется: страница содержит изображение.
- Светлая и тёмная темы, компактное меню, управление с клавиатуры, учёт настройки уменьшения анимаций.

## Сохранение и личные данные

Прогресс, фамилия, имя, класс и тема хранятся только в localStorage этого браузера для данного адреса сайта. Они не отправляются на сервер и не переносятся между устройствами. Локальная копия и GitHub Pages имеют разные хранилища. В приватном режиме или при запрете сохранения данные могут исчезнуть после закрытия или обновления страницы; сайт продолжает работать в текущем сеансе. При очистке данных браузера прогресс удаляется.

Кнопка «Сбросить прогресс» требует подтверждения и удаляет результаты обучения и даты сертификатов, сохраняя имя, класс и тему. Уход из текущего теста сбрасывает незавершённую попытку; законченный лучший результат остаётся. Повторное решение не увеличивает счётчики.

## Структура проекта

- `index.html` — оболочка, меню и подключение ресурсов.
- `styles.css` — оформление, темы и адаптивность.
- `data.js` — уроки, задания, ответы и вопросы тестов.
- `app.js` — навигация, проверка ответов и сохранение прогресса.
- `certificate.js` — Canvas и компактный экспорт PDF без сторонних библиотек.
- `favicon.svg` — собственный логотип с D и символами кода.
- `CHECKS.md` — результаты и ограничения проверки.

Сторонние библиотеки, изображения и файлы шрифтов не используются; лицензии на сторонние ресурсы не требуются. Используются системные шрифты Segoe UI / Arial / sans-serif и Consolas / monospace. Все учебные задания сверяются с подготовленными ответами: сайт не запускает Python и не выполняет введённый код.

Сертификат является учебным сувениром школьного проекта, а не официальным документом об образовании.
