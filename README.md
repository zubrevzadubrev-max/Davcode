# DavCode — учись и создавай

Обновление школьного проекта Русинова Давида, ученика 11А класса. Прежние уроки, оформление, результаты и сертификаты сохранены. Сборка, регистрация и серверная часть не нужны.

## Проверка локально

Открой `index.html` из этой папки в современном браузере. Все ресурсы, включая музыку, лежат внутри неё. Можно также открыть терминал в этой папке, выполнить `python -m http.server 8000` (если установлен Python) и перейти на `http://localhost:8000`. Это только статическая раздача файлов.

При открытии через `file://` некоторые браузеры ограничивают localStorage; сайт продолжит работать в текущем сеансе.

## Обновление существующего репозитория GitHub

1. Войди в GitHub, открой **свой существующий репозиторий DavCode**, вкладку **Code**, ветку **main**.
2. Нажми **Add file → Upload files**.
3. На компьютере открой папку **«гитхаб»** и перетащи **всё её содержимое** в область загрузки: файлы, папки `assets` и `licenses`. Включи показ скрытых файлов, если `.nojekyll` не виден.
4. Загружай содержимое, **не внешнюю папку «гитхаб»**. `index.html` должен оказаться в корне репозитория рядом с `app.js`, иначе по прежнему адресу может остаться старая версия.
5. Проверь список файлов и нажми **Commit changes** в `main`. Совпадающие имена заменят прежние версии.
6. Открой **Settings → Pages**. В **Build and deployment → Source** выбери **Deploy from a branch**, ветку **main** и папку **/(root)**, затем **Save**. Если эти настройки уже установлены, менять их не нужно.
7. Дождись публикации и открой ссылку из Pages. При необходимости принудительно обнови страницу, **не удаляя данные браузера**.

Инструкция сверена с [официальной документацией GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site). Относительные пути подходят для `https://username.github.io/davcode/`.

### Что удалить из старой версии

Рабочие файлы прежнего сайта удалять специально не нужно: все они включены и заменяются актуальными. Добавляются `extra-data.js`, `enhancements.css`, `music.js`, `audio.js`, `MUSIC_CREDITS.md`, `assets/music` и `licenses`.

Если ранее в репозиторий были загружены `davcode-site.zip`, `qa`, `node_modules`, временные файлы или лишние внешние папки `davcode-site` / `для гитхаба`, они для этой версии не нужны. Их можно удалить **после проверки, что актуальный index.html и остальные файлы этого комплекта находятся в корне**. Не удаляй собственные материалы других проектов. ZIP в этой поставке не нужен.

## Добавленные функции

- Три курса по четыре урока: «Python в повседневных задачах», «Создаём красивую веб-страницу», «Первые шаги в JavaScript».
- 18 новых заданий и три новых теста по пять вопросов. Итого: **20 уроков, 30 заданий, 5 тестов**.
- Карточки со статусом и прогрессом, избранное, блок «Следующий шаг».
- Раздел «Практика»: три проекта с пошаговыми инструкциями, решениями и сохраняемыми чек-листами; справочник из 18 статей с поиском.
- Новые достижения и три сертификата с прежним экспортом PNG/PDF. Для нового сертификата нужны четыре урока и минимум **4/5** в итоговом тесте. Прежние условия сертификатов не изменены.
- Плеер, мини-режим, жанры, перемотка, громкость, mute и автоматическое переключение после конца трека; независимые звуковые эффекты.

## Плеер и настройки

Нажми ноту в верхней панели, затем «Слушать». Само открытие окна музыку не включает. На компьютере окно перемещается за заголовок мышью или стрелками клавиатуры при фокусе на заголовке. «Свернуть» сохраняет музыку, «Закрыть» ставит на паузу. Повторное открытие в текущем сеансе сохраняет трек и позицию. На телефоне плеер становится раскрывающейся нижней панелью; страница получает дополнительное место для прокрутки.

Шестерёнка открывает настройки. Музыка и эффекты имеют отдельную громкость; выключение эффектов не выключает музыку. При совпадении учебных событий звучит один эффект с приоритетом сертификата / достижения. Быстрые нажатия не наслаивают звуки.

### Музыкальная подборка: оставшееся ограничение

Включены **6 разных инструментальных треков**: 2 рэп-бита, 2 хип-хоп-композиции, 2 электронные записи. Файлы локальные MP3, каждый меньше 25 МБ. Авторство и лицензии доступны в плеере и [MUSIC_CREDITS.md](./MUSIC_CREDITS.md); тексты лицензий находятся в `licenses`.

**Не хватает двух обязательных фонк-треков**, поэтому подборка из 8–10 композиций пока не укомплектована. Найдены Phonk ish и Phonk Remix автора HoliznaCC0, однако источник возвращает HTTP 403. Они не добавлены как неработающие пункты и не заменены другими жанрами. Для завершения нужны эти два разрешённых файла либо другие две инструментальные фонк-композиции с подтверждёнными источниками и лицензиями. Подробности — в MUSIC_CREDITS.md.

## Прогресс и личные данные

Ключ `davcode.v1` сохранён, внутренняя версия данных стала 2. Идентификаторы старых материалов не меняются. Новые уроки имеют ID 9–20, задания — 13–30. Профиль, лучшие результаты, старые достижения и даты выданных сертификатов сохраняются.

Общий процент: `(пройденные уроки + решённые задания + сданные тесты) / 55 × 100%`, с округлением. Прежние 100% сразу после расширения становятся 40%: 22 старых элемента из 55. На странице прогресса есть пояснение: «Добавлены новые материалы — ваши прежние результаты сохранены». Старые сертификаты остаются доступными. Проекты отмечаются по **самопроверке**, не входят в процент и не открывают сертификаты.

Прогресс, избранное, самопроверки и настройки хранятся **только в браузере пользователя для текущего адреса сайта**. Звук использует отдельный ключ `davcode.sound.v1`. Позиция и выбор композиции живут в памяти текущего сеанса; после перезагрузки автозапуска нет.

Обновляй тот же репозиторий по прежнему адресу, не очищая данные сайта. Другой домен или локальная копия имеют отдельное хранилище. Данные ученика никуда не отправляются. При запрете localStorage всё продолжает работать в текущем сеансе.

Сброс требует подтверждения и очищает учебные результаты, достижения, даты сертификатов и самопроверки; профиль, тема, избранное и звуковые настройки остаются.

## Устройство сайта

`data.js` — прежние материалы, `extra-data.js` — новые курсы, справочник и проекты. `app.js` — интерфейс обучения и миграция. `audio.js` — один HTMLAudioElement и эффекты Web Audio. `music.js` — сведения о включённых файлах. `certificate.js` — прежний экспорт Canvas/PDF.

Сторонних библиотек и загружаемых шрифтов нет. Иконки и обложка созданы CSS/SVG, шрифты системные. Введённый код не выполняется; ответы сверяются с подготовленными вариантами.

Проверки и их ограничения описаны в [CHECKS.md](./CHECKS.md). Публикация не выполнялась: папка подготовлена для ручной загрузки.
